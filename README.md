# ChatNoteUki

只面向 Windows 的个人认知伙伴。你直接记录，AI 优先归入已有活动问题，为每条笔记生成标题与简短回应；长笔记生成摘要，短笔记直接预览原文；你的原话与思想演变永久保留。

## 安装与首次使用

1. 安装 `release/ChatNoteUki-0.2.3-Setup-x64.exe`，或运行 `release/win-unpacked/ChatNoteUki.exe`。
2. 打开「设置与数据」，填写自己的 DeepSeek API key。默认使用 `deepseek-flash`，自动分类、标题、概述和简短回应合并为一次调用。
3. 可立即离线记录。未配置 key 的记录先显示原文首行和「待生成」；配置后依序处理。失败任务仅手动重试，已成功的任务不重复调用。
4. 可选：配置坚果云 WebDAV，填写服务器地址 `https://dav.jianguoyun.com/dav/`、坚果云账户和**第三方应用密码**，默认目录 `ChatNoteUki`。不要填写坚果云登录密码。

本地数据位于 `%APPDATA%/ChatNoteUki/`（Electron 的 Windows userData 目录）。卸载保留数据；API key 和 WebDAV 密码使用 Windows DPAPI 加密，只能由对应 Windows 用户解密。程序源码、安装包、云端备份均不包含你的凭据。

高级用途可通过进程环境变量 `UKI_DATA_DIR` 指定独立本地资料目录；安装包验收使用此方式隔离测试数据，不操作你的日常思想库。

## 升级到 0.2.2：只把旧笔记原文重新输入

直接安装新版，安装程序保留本机资料与凭据。首次打开旧资料库时，在资料目录的 `backups/before-raw-reimport-*.db` 单独备份旧库，再用一次事务将笔记重新作为新记录输入。使用自定义 `UKI_DATA_DIR` 的用户须继续使用原目录；实际路径可在「设置与数据」确认。

只导入每条笔记最后一次更正后的正文，保留顺序、重复内容和原记录时间。旧用户追问与 AI 对话不导入；旧线程、认知、标题、摘要、建议和任务不进入新工作区。所有重导笔记使用新 ID，从零生成标题、摘要、回应和分类建议，不提供旧版归属或历史线程入口。

重导只执行一次，事务失败整体回滚；重启、查询投影重建和云端恢复不重复重导。重导后的新输入优先处理，自动处理使用 Flash，遵守每日 AI 预算；不足时保留待处理状态，次日继续，计费不明的请求须手动重试。密钥和坚果云密码保持本机原配置。

恢复清单和新事件文件升级为格式 3，仍读取格式 1、2。已有云端不可变文件不改写，旧事件作为恢复链中的备份保留；重导事件之后的当前思想库只包含重新输入的笔记及其新内容。本地事件日志也保留恢复依据，旧信息不会进入日常界面、搜索或 AI 上下文。导入凭据及已消耗的预算保留，以免重复导入或重算费用。**升级后不要用旧版继续维护该资料库**。需要回滚时，停止新版同步，在独立目录使用升级前备份，避免旧程序覆盖当前云端清单。

## 工作区与整理

左栏提供全部记录、待整理、整理建议、回顾及主问题／子问题树，最多两层。默认记录无需选择问题；无法确定归属时保留待整理，由 AI 提出新问题建议，确认后才建立节点。同名、同层的待审批新问题合并依据，避免每条笔记出现重复建题建议；接受时也可选择归入已有问题。可以手动创建、改名、修改说明、调整上级或归档问题。

中间按时间推进笔记、讨论及审批单元，输入框固定在底部。一条笔记与 AI 回应保留在同一单元；继续讨论关联起始笔记的具体版本，并作为新的时间线单元。新页最多 30 个单元，可向前、向后翻页或定位日期；长正文按需读取。查看旧内容时，新增记录显示提示，保留阅读位置。

展开笔记后点击「回复 AI」，可直接在该卡片中追问、补充或纠正，关联讨论在卡片内展示，支持多轮对话。待整理笔记也可回复，不必先建立线程；回复始终沿用起始笔记归属，不单独生成建题建议。卡片回复草稿仅本机保存，关闭卡片或重启后再次打开可恢复，Ctrl + Enter 发送。底部输入框只记录新想法，讨论统一从笔记卡片进入。

单条笔记对话优先读取该笔记指定版本及近期关联问答，不串入其他笔记；线程回顾和认知分析在现有上下文预算内纳入用户补充与 AI 回答。原文与 AI 回答分别标记，AI 的说法不能视为用户认同。普通笔记分类仍只以用户原话为依据。

右侧用于问题概览、已确认认知、未解决问题和回顾。原文引用在右侧展开，不切换中间工作区；可加宽或最大化为阅读层，退出后恢复布局。窄窗口使用覆盖式资料栏。左右栏宽度、阅读字号、展开状态、各工作区草稿及阅读位置只保存在本机。新版自行归档的问题集中在左侧「已归档问题」，可进入管理并重新启用。

整理建议显示理由、引用版本、前后结构和影响数量；支持逐项或多项接受、拒绝和暂缓。合并须明确目标问题，来源认知留在历史资料，目标认知保持原版本。建议过期后须重新生成；相同依据的拒绝、暂缓持久保存。结构操作可撤销，相关内容已有后续修改时停止直接撤销并提示核对。

更正正文追加新版本，初始原话保留；手动标题和归属不会被后续 AI 覆盖。默认自动任务使用 Flash，Pro 只在主动讨论或分析时手动选择。

快捷操作：`Ctrl + Enter` 保存；记录按钮按 `Enter` 展开；`Alt + PageUp` 更早一页，`Alt + End` 回到最新。资料阅读层按 `Esc` 退出；审批按钮支持键盘聚焦操作。

## 手机输入

手机使用现有编辑器修改坚果云目录下的 `inbox.txt`；本项目不制作手机应用。示例：

```text
我现在如何理解职业路线？
这行仍属于同一条笔记。

今天关于城市密度的新想法。

我想重新检验之前的判断。
```

空行分隔笔记，单次换行保留在原文里。兼容 UTF-8（含 BOM）及 CRLF、LF、CR、混合换行和带空格的空行。最后一条不必以换行结尾；空白内容不导入。

先完成手机上传，再启动 Windows 或点击「同步」。Windows 按文件顺序保存原文、归档到云端并发布恢复清单，随后使用强 ETag / `If-Match` 条件清空。AI 失败不会影响已保存的原文，也不会阻止安全清空。

发生追加冲突时只导入新增部分；既有内容被改写时，保存冲突快照并暂停清空，请核对手机文件。服务器不支持条件写入或 inbox 没有强 ETag 时，程序保留原文并显示原因，不无条件清空。

0.1.1 已实测适配坚果云：内部规范化其未加引号的 ETag，条件更新时发送服务器返回的原始标识。由于坚果云会忽略 `If-None-Match: *`，新文件先上传到唯一临时路径，再使用 `MOVE` 和 `Overwrite: F` 创建目标，保护已有归档与恢复清单。首次连接仍验证这些保护实际有效，验证失败就暂停清空。

**限制：**条件写入只能防止服务器当时的并发覆盖，不能阻止手机编辑器稍后上传旧副本。不要在 Windows 导入时让手机继续编辑旧副本；读到旧内容重新出现时先核对。相同文字可以是你有意记录的新笔记，程序不会永久按内容去重。

## 思考与观点版本

- 主入口无须分类；已有线程中也可以继续记录。讨论从卡片「回复 AI」进入，只有主动讨论和分析允许手动选择 Pro。
- 标题与预览用于列表和搜索。去除首尾空白后不超过 120 个 Unicode 字符，且中文句子分段不超过两句时，显示深灰「原文」；长笔记显示蓝色「AI 摘要」。已有短摘要仍保留，但不作为列表预览。点击记录查看正文版本与独立 AI 回应。
- 原文、标题、摘要检索与 AI 回应检索分开，支持 FTS5 trigram 及短关键词匹配。分类和观察不把 AI 回应当作用户立场。
- 「检查认知变化」对照已确认认知生成候选修改，只有接受或修改后接受才能更新右侧。「生成线程回顾」总结当前问题的记录和讨论，附原文引用，区分明确表达、AI 推测与继续追问。两者都显示提交、排队、生成、预算等待、失败及完成状态；完成后可以直接查看中间结果，回顾同时在右侧展开。未配置密钥或没有记录时显示原因。
- 左侧「回顾」集中保存所有成功生成的线程总结，显示所属问题、日期与原文引用，可点击「进入问题」继续查看。该入口不会自动调用 AI；排队或失败的任务在相应问题右侧查看和重试。空白时会说明生成入口。旧版回顾页的未发送草稿仍可编辑和保存。
- 「有新内容」只依据当前工作区及筛选条件中的新增条目，不把 AI 用量、任务状态或其他问题的更新当作新内容。「查看最新」保持当前工作区，重新加载最新页；查看回顾结果会清除笔记搜索及 AI 状态筛选，避免隐藏结果。
- JSON 提示提供完整字段示例，兼容回顾的文字列表及空的可选笔记元信息；原文引用仍校验是否属于本次上下文。标题与简短 AI 回应超限时截短并加省略号，长笔记摘要不机械截短。空返回、输出截断和具体字段问题分别提示，失败请求保留实际用量且不自动重复调用。格式示例依据 [DeepSeek JSON Output 文档](https://api-docs.deepseek.com/zh-cn/guides/json_mode/)。
- 当前已确认认知、近期原文与检索到的相关历史组成有限上下文；单次输入保守控制在 8,000 tokens 内。超长原文仍能保存，但可能需拆分后再处理。
- 每日输入默认 100,000 tokens、输出 12,000 tokens，可在设置调整。网络中断可能已被供应商计费，因此仅显示已返回结果的实际用量，不宣称精确账单。
- 未确认的请求按单次最大输入及输出保守计入当日预算，避免断网或重启绕过预算；返回实际用量后替换预留额。明确授权失败、余额不足和限流响应会释放预留额。

## 完整备份与换机

云端目录包括 `inbox.txt`、`imports/` 原文件归档、`events/` 不可变思想事件以及 `manifest.json` 版本化恢复清单。SQLite 只在本地运行，禁止把打开中的数据库直接放进坚果云同步目录。

桌面记录、AI 元信息、回应、认知审批和任务状态先本地提交，通过持久化事件队列异步备份。默认开启自动同步：启动时同步一次，运行期间每分钟读取手机 inbox，本地记录与修改在最后一次保存约 3 秒后上传。上传、手机导入、手动同步和恢复串行执行，避免同时写入。断网时照常记录，自动重试逐步退避至最多 15 分钟，成功后恢复正常间隔。

条件写入能力按服务器、账户、目录、凭据修订号和适配器版本缓存 30 天；到期或异常后，在下一次需要写入时重新验证。缓存有效、无待上传变化且入口未变的周期，最多读取入口和清单，不创建目录、不探测、不写文件。未知清单变化仍核对历史与设备所有权。设置页提供资料路径、待上传数量、检查时间、读写统计和只包含方法、相对路径、状态及耗时的诊断。

在「设置与数据」可关闭自动同步，或把手机输入检查间隔改为 2、5、10 分钟。关闭后仍可手动同步，启动时仍同步一次；退出应用后不运行后台任务。请先完成手机上传，条件清空无法解决手机编辑器的旧副本回传。

初始化过但尚未保存任何事件的空云端库，会使用条件写入重新绑定当前本地库，保留本地未上传笔记。已有事件的云端库仍禁止自动换机接管；同步失败时不删除本地库，也不要删除数据库来绕过保护。

换机：停止旧电脑同步，在新电脑的空白资料库配置相同坚果云账户和目录，保存设置，再点击「从云端恢复并接管」。恢复后会重建原文、标题、概述、线程、对话、认知版本与未完成任务；旧电脑将因维护设备不同停止写入。凭据不随思想库迁移，新电脑需重新填写。首版不支持多台 Windows 并发编辑。

云端思想数据为可读 JSON 和文本，经 HTTPS 传输，不是端到端加密。不要把应用凭据写入笔记。已发起但中断的 AI 任务标记为失败，防止重启后自动产生重复费用。

## 开发与检查

需要 Windows 10/11 x64、Node.js 24 和 npm。SQLite 使用 Electron/Node 自带的 `node:sqlite`，不依赖本机编译器或外部数据库。

```powershell
npm ci
npm run dev
npm test
npm run test:desktop
npm run dist
npm run verify:secrets
```

`npm test` 使用模拟 AI/WebDAV，不产生模型费用。桌面测试也模拟 AI，并使用 `.local/` 隔离数据。`node scripts/live-smoke.mjs` 是显式真实联调入口，需仅为该进程设置 `DEEPSEEK_API_KEY`；最多 3 次 Flash 请求，报告不包含 key，测试凭据仅 DPAPI 加密保存于被 Git 忽略的 `.local/`。

`scripts/live-feedback.ts` 是需显式授权的真实 Flash 验证：从本机已保存的 DPAPI 凭据读取 key，只发送合成笔记，不连接 WebDAV；默认最多 4 次调用检查短笔记、长笔记、回顾及结构整理，`--note-only` 只验证一条笔记。单次运行硬限制 5 次调用、20,000 输入 tokens、4,000 输出 tokens，报告只记录字段类型、长度和用量。自定义凭据路径使用 `UKI_LIVE_CREDENTIALS_PATH`，不把 key 放进脚本。

`scripts/configure-webdav.ts` 提供显式坚果云配置与隔离联调：从进程环境读取 `UKI_DAV_USER`、`UKI_DAV_PASSWORD`，可选 `UKI_API_KEY`，加密写入正式本机资料目录；在唯一临时子目录验证三条笔记的导入、清空和恢复，随后删除测试目录。验证成功后初始化正式备份，只在入口不存在时创建空 `inbox.txt`，不清空已有入口。此脚本不调用 AI。请勿把环境变量的实际值写入源码或命令脚本。

```powershell
npm exec -- esbuild scripts/configure-webdav.ts --bundle --platform=node --format=cjs --target=node24 --external:electron --outfile=.local/configure-webdav.cjs
npm exec -- electron .local/configure-webdav.cjs
```

GitHub Actions 在 Windows 上运行类型检查、单元测试、桌面测试和安装包构建，生成可下载的安装包 artifact。首次原型安装包未签名；应用升级暂为手动安装，不自动删除数据。

`scripts/verify-webdav-v2.ts` 使用本机已保存的 DPAPI 凭据在唯一 `verify-v2-*` 子目录验证 v2 导入、更正、任务恢复及空闲零写入，随后清理本次目录；不保存配置、不读写正式入口、不调用 AI。

`tests/desktop/raw-reimport.spec.ts` 使用隔离合成旧库验证原文重导、备份、凭据保留和重启，设置 `UKI_TEST_EXE` 可验证已安装程序。`scripts/upgrade-smoke.mjs` 保留为 0.2.0 的旧验收脚本，不适用于当前升级。`scripts/packaged-smoke.mjs` 可接受已安装 EXE 路径，检查离线记录、重启和安全配置。

## 当前边界

只做 Windows 10/11 x64；没有手机应用、向量数据库、知识图谱、联网研究或多人格。坚果云服务器真实条件写入能力会在首次连接时用独立临时文件验证。本次真实 WebDAV 验证已通过，其他账户与手机编辑器仍应确认上传完成及旧副本处理方式，模拟测试不替代真实验证。
