# ChatNoteUki 0.5.0

0.5.0 的 [升级与使用说明](docs/UPGRADE-0.5.0.md) 和 [交付检查](docs/IMPLEMENTATION-0.5.0.md)。保留 [Flownote 代码对照](docs/FLOWNOTE-COMPARISON.md) 与 [15 张功能候选卡](docs/NEXT-FEATURE-CANDIDATES.md)，本轮实现保存查询、摘录想法和所选笔记分析。

面向 Windows 10/11 x64 的个人思想工作区。先保存原话，再由 AI 整理标题、分类、摘要与简短回应；离线可以记录。三栏分别承载问题树、笔记与对话、备查资料。记录和 AI 判断明确分开，认知变化须经用户确认。

## 安装和升级

从 [GitHub Releases](https://github.com/tob124/ChatNoteUki2/releases/latest) 下载 ChatNoteUki-0.5.0-Setup-x64.exe，直接安装升级。安装程序和卸载保留资料。实际目录见「设置与数据」，默认 `%APPDATA%/ChatNoteUki/`；可用 `UKI_DATA_DIR` 指定独立目录。

升级前自动创建 `backups/before-0.5.0-*.db`。现有正文、更正、人工标题和归属、认知、草稿及凭据保留，不重复已经完成的旧原文重导。云端格式升级为 **6**，继续读取 1–5，旧程序不能继续维护格式 6。详见 [升级说明](docs/UPGRADE-0.5.0.md)。

API key 和 WebDAV 第三方应用密码用 Windows DPAPI 加密，只在对应 Windows 用户本机保存，不进入源码、日志或云端备份。思想数据以可读 JSON、文本和文件通过 HTTPS 托管到坚果云，并非端到端加密。凭据和未提交草稿不随换机恢复。

## 记录、讨论和整理

默认直接记录，无须先选问题。本机保存、AI 处理和云端上传有各自状态。自动任务使用 deepseek-flash；Pro 只在主动深入讨论或认知分析中手动选择。

每条笔记生成自己的标题。去除首尾空白后不超过 120 个 Unicode 字符且中文句子不超过两句时，列表显示深灰「原文」；长笔记显示蓝色「AI 摘要」。长度是写作目标，完整返回文字保存，列表只做预览。有效标题、摘要或回应不会因分类失败而丢失，显示部分完成并可重试。

卡片「回复 AI」讨论同一条笔记，指向起始正文版本。对话每页最多 30 条，支持更早对话，一轮问答不拆开。线程回顾纳入用户补充与关联对话，AI 回答不会被当成用户立场。底部输入框只记录新想法。

问题最多两层，支持创建、修改、归档、置顶和整理审批。AI 优先使用已有活动问题，无法确定则保持待整理并提出建议，不能自行创建节点。历史整理在前台任务空闲时运行，每批最多 10 条；新记录和主动操作优先。拒绝、暂缓及基础版本持久保存，过期建议不能直接应用。

卡片菜单提供编辑、移动、复制、导出、收藏、附件和删除。更正追加正文版本，手动标题和归属不被 AI 覆盖。普通删除进入回收站，可撤销、恢复或彻底删除，不自动清空。彻底删除清理原文、更正、关联讨论、重导前对应原文、应用自动备份及当前云端恢复文件；其他笔记与已生成的回顾、认知和分析保留，旧引用显示「笔记已删除」。不清理坚果云自身历史版本、服务端回收站或手动导出的副本。

认知可直接手动编辑，无须 AI；恢复历史版本也保存为新版本，均校验基础版本。「检查认知变化」提出候选修改；「生成线程回顾」归纳记录并给出引用、推测和继续追问，点击才调用 AI。左侧「回顾」保存已有结果。

搜索显示范围和命中来源，默认检索当前正文、标题、摘要；「包含更正历史」加入旧正文，AI 回应单独检索。引用在右侧打开，可以查看最新正文、定位原记录，再返回查找位置。工作区保存分页、展开项、位置及草稿，新内容不强制滚动。正文、标题、认知、建议编辑草稿可重启恢复，基础内容变化时提示核对。

搜索行的「筛选与查询」可保存常用条件，再次打开会恢复范围和阅读位置。选择当前页笔记后出现「分析所选」，只读取确认的最新正文，结果进入「回顾」，不修改归属或认知；移动、导出和删除收进「更多操作」。

快捷操作：Ctrl+Enter 保存，中文输入法组合期间不发送；Alt+PageUp 更早记录，Alt+End 最新记录，Esc 关闭菜单或阅读层。两侧可收起，窄窗口资料栏为覆盖层；动效尊重系统减少动效设置。

## AI 容量与失败处理

结构任务使用 [DeepSeek Responses API](https://api-docs.deepseek.com/guides/responses_api/) JSON Schema；讨论用普通文本流式回复。外部检索使用原生搜索接口，不使用 Responses 中被忽略的搜索工具。

安装包带官方 tokenizer，离线计入提示词和结构定义并保留余量。默认输入目标 32K tokens，高级设置最高 128K；长资料分段处理，保存覆盖范围和检查点。默认输出：笔记 2K、讨论 8K、整理/回顾/认知/资料综合 16K，截断允许一次扩容重新生成，最高 32K。

每日输入 500K / 输出 100K 是提醒阈值，不暂停任务；可选硬上限，旧预算值迁移为提醒阈值。API 实际用量为最终统计依据，未知计费请求保守预留用量，缺失 usage 标为待核对。

返回响应、用量和步骤标记先落盘，再解析应用。安全归一化后允许一次格式修复，每个步骤含重试与修复最多三次请求。限流和可恢复服务错误延迟退避；鉴权、余额、参数错误给出处理方法。完成步骤及有效分项复用，可能计费的中断等待人工重试。写入前复查正文、归属、删除和认知基础版本。任务面板显示阶段、等待原因、失败步骤及结果，可取消、定位对象和重试。

## 附件、听写和资料

选择或拖放 PDF、DOCX、TXT、Markdown，单文件 25 MiB。可关联笔记或独立保存为资料，独立资料不制造用户原话。先保存原文件，再独立进程提取纯文本并建立中文索引，不执行文档脚本或加载外部资源。

PDF 保留页码，DOCX/文本保留段落；最多提取 100 万字符，显示实际覆盖范围，不宣称读取了完整长文。文字、分段摘要与完整结果分别保存；失败仍可阅读、搜索、打开和另存原文件，重试复用完成分段。无文字、加密和损坏分别提示。本轮不支持扫描件 OCR、图片摘要、应用内录音转写。

回复时明确选择关联资料，才将已读取内容作为参考；资料不自动成为用户认知。原文件按哈希分块备份，换机按需下载并验证，删除资料只清理没有其他引用的文件。

阅读资料时选中文字，可「摘录并记录想法」。逐字引用与自己的理解分别保存，笔记展开后可核对来源，导出分别标记。来源删除后保留自己的正文，旧引用显示已删除。

「系统听写 · Win+H」定位输入框并提示使用，由 [Windows 处理听写](https://support.microsoft.com/en-us/accessibility/windows/use-voice-typing-to-talk-instead-of-type-on-your-pc)，需要网络和麦克风。文字先进入草稿，核对后保存，不自动发送。

「查找资料」由用户主动发起，发送前确认可公开的搜索词。最多两次客户端检索及四个公开静态来源，保留逐字引文和实际读取范围；未读取、登录或付费内容不作为已核实依据。供应商内部搜索次数及上下文不由客户端完全控制，实际用量可能高于客户端预算。失败重试复用检索及成功读取。见 [0.3 资料设计](UPGRADE-0.3.md)。

## 手机、同步和换机

设置页填写 `https://dav.jianguoyun.com/dav/`、账户、第三方应用密码和目录（默认 ChatNoteUki）。手机编辑 inbox.txt，空行分隔笔记，单次换行保留，兼容 UTF-8 BOM、CRLF/LF/CR、空白行、末尾无换行及重复文字。

先完成手机上传，Windows 按顺序导入。事务保存原文和导入凭据，上传不可变归档并确认清单后，以强 ETag/If-Match 清空，不等待 AI。追加冲突只导入新增部分，改写保留快照等待核对，不无条件覆盖。手机编辑器之后回传旧副本无法由条件写入阻止，导入时勿继续编辑旧副本。

默认启动同步、每分钟检查、本机保存约三秒后上传，串行执行并失败退避。缓存有效、无新事件且入口未变时最多读取入口和清单，零写入。状态更新和 AI 进度不触发备份。设置区分最近检查、最近成功上传、待上传量；诊断只记录方法、相对路径、状态和耗时。

SQLite 不直接同步运行中的数据库。云端保存 imports/、events/、blobs/ 和版本化 manifest.json；恢复包括笔记、派生信息、对话、认知、审批、资料和未完成任务。单台 Windows 维护：换机停止旧设备同步，在新电脑空白库配置相同目录，执行「从云端恢复并接管」，旧设备停止写入。退出先完成本机草稿保存，云端待办下次继续。

## 开发、验证和发布

Windows x64、Node.js 24，SQLite 为运行时自带 node:sqlite。

```powershell
npm ci
npm run typecheck
npm test
npm run test:desktop
npm run dist
npm run verify:secrets
```

日常测试用模拟 AI/WebDAV 和隔离合成资料，没有模型费用。真实验证须明确授权：scripts/live-quality.ts 从本机 DPAPI 读取 key，只发合成任务，最多 80 请求/输入 1M/输出 150K，未知计费保守计入额度。0.4.0 的 35 任务结果见 [质量报告](docs/AI-QUALITY-0.4.0.md)。scripts/verify-webdav-v2.ts 只使用唯一隔离子目录验证格式 6 导入、恢复、资料与删除，并清理，不访问日常入口或调用 AI。

GitHub Actions 每次 main、codex/** 推送、PR 或手动触发检查、测试并构建。main 通过后自动发布安装包与 SHA256SUMS，标签为 v版本-main.提交前12位；资产核验摘要后正式发布，只有当前 main 头提交标记 Latest。重跑不替换已发布资产。安装包未签名，升级手动安装。

scripts/packaged-smoke.mjs 验证实际打包程序离线记录、附件提取、重启与安全配置；scripts/upgrade-smoke.mjs 验证实际安装升级、资料和凭据。验收使用 .local 合成资料，报告及数据库不提交。
