# 升级到 0.4.0

直接安装 Windows x64 新安装包。资料路径保持不变，自定义 UKI_DATA_DIR 继续使用原目录。升级前数据库备份位于 backups/before-0.4.0-*.db，凭据在独立 DPAPI 文件中，不加入数据库备份。

0.3 的正文、更正、人工标题及归属、线程、认知、任务、用量和本机草稿保留。完成的旧原文重导不重复；更早且尚未重导的版本仍按规则只重导最新笔记正文，排除旧对话和派生信息，保留顺序、重复文字和原记录时间。

查询投影可以重建，升级备份只创建一次。中断且计费不明的 AI 请求等待人工重试；有效返回和完成步骤复用。默认预算为提醒，启用硬上限才暂停；历史整理及附件分段在前台任务空闲时继续。

云端格式 5 能读取 1–4，旧程序不能维护格式 5。换机安装本版本或更新版，在空白库恢复并接管；凭据和未提交草稿留在本机，换机重新填写密钥和密码。

普通删除可恢复。彻底删除清理原文、更正、关联讨论、重导前对应原文、应用自动备份、当前云端事件和无共享引用文件。条件发布并确认清单后才清理旧文件，中断后续跑。已有回顾、认知和其他分析保留，旧引用显示已删除。用户手动导出、坚果云历史版本及服务端回收站由用户管理；自动备份不能撤销永久删除。

附件 PDF/DOCX/TXT/Markdown，25 MiB，最多提取 100 万字符并显示范围；扫描 PDF 和图片 OCR 延后。Win+H 使用 Windows 听写，没有应用内录音，不自动发送。

回滚请停止新版同步，在独立目录核对升级前备份，勿让旧程序接管当前清单。安装和卸载保留日常资料；验收脚本只操作隔离合成资料。
