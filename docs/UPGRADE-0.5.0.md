# 升级到 0.5.0

直接运行 Windows x64 安装包。资料目录不变，保留笔记、人工标题和归属、对话、认知、附件、任务、草稿以及本机 DPAPI 凭据。已有资料库首次由新版打开时，先创建 `backups/before-0.5.0-*.db`，不重复旧原文重导。

云端格式为 **6**，读取格式 1–5。保存查询、摘录来源和指定范围分析随事件恢复；凭据、未提交草稿和阅读位置仍只在本机。不要让旧版本继续维护新版云端清单；换机使用 0.5.0 或更新版本，在空白库恢复并接管。

## 三个入口

- **保存查询**：输入关键词，在「筛选与查询」里调整范围、AI 状态及更正历史，再保存名称。下次从同一入口打开，可重命名和删除。查询保存条件，不复制笔记；删除查询不会删除笔记。原问题不存在时会提示核对，不自动替换搜索范围。
- **摘录并记录想法**：在「资料」阅读层选中同一段中的文字，再记录自己的理解。键盘聚焦段落、按 Enter 可摘录整段。引用逐字保存，用户正文单独保存。收起后重新选择相同范围可恢复本机草稿；更换摘录范围不会覆盖另一份草稿。笔记展开后用「核对参考摘录」查阅来源；导出分别标记正文和参考引文。
- **分析所选**：在当前页选择独立笔记，确认具体问题和所选标题，再开始。只读取最多 30 条所选笔记的最新正文，不包含其他记录或对话。结果放在已有「回顾」页，并附原文引用。线程回顾仍纳入关联对话。分析不移动笔记、不更新认知；容量不足时先提示缩小范围，不悄悄省略正文。重复点击定位同一待完成任务。

日常搜索行只保留关键词和一个展开入口；多选工具栏仅在选择后出现，移动、导出、删除放进「更多操作」。没有新增一级导航。分析问题及摘录想法自动保存本机草稿，失败时保留输入，Escape 可关闭展开层或弹窗。

资料删除后，新 AI 上下文不再使用该摘录。彻底删除来源会清理引用的源文副本，自己的笔记正文保留；已生成的分析按现有规则保留。提取文字改变而原文件相同时，旧引用显示核对提示。永久删除不能通过自动备份撤销；坚果云历史版本、服务端回收站及手动导出副本仍由用户管理。

如需核对升级前备份，停止新版同步，在独立目录打开备份；不要用旧程序接管当前清单。安装和卸载保留日常资料。
