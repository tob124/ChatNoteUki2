# Liquid Glass 工作区实验

分支：`codex/liquid-glass-workspace`。基线：0.5.1 / `caa6e8c`。稳定 main 与日常资料保持独立。

## 设计与布局

方向是可阅读的桌面工作区：白色内容平面、石墨色正文、低饱和蓝色强调。微软雅黑 / Segoe UI，正文默认 14px，工具 12px。玻璃只用于导航和操作平面，不用于笔记正文，不叠加玻璃。

```
┌ 导航 200px ┬ 标题 / 搜索 / 紧凑操作 ─────────┬ 资料 280px（按需）┐
│ 新想法     │ 问题工具：思考 / 查证 / 更多    │ 概览、已确认认知 │
│ 记录与问题 │ 笔记原文 → 回应 → 卡片内讨论   │ 引用与历史结果   │
│            │ 进行中的工作展开，完成收为结果行│                  │
│ 次级入口   │ 底部悬浮输入区：附件 / 保存    │                  │
└────────────┴──────────────────────────────┴──────────────────┘
```

日常页面收起右栏；打开资料不改变阅读位置。宽窗口可三栏，窄窗口资料覆盖。标题、搜索、分页合并为紧凑行，日期定位按需展开。任务及编辑在中间，右侧负责查阅。悬浮位置限定为输入区、上下文工具与选择工具；卡片操作不漂浮到正文上。点击目标至少 28px，触屏适当加大；保留文字、键盘焦点与减少动效。

本机提供「玻璃 / 素雅」切换以及「减少透明效果」。不开启持续动画，不使用 WebGL、折射着色器、鼠标跟随光效或整页模糊。玻璃限于小范围 CSS 背景滤镜，关闭透明后不执行模糊。

## 技术选择

继续 Electron / React。Apple 原生 Liquid Glass 属于 Apple 平台；Windows 的 CSS 实验借鉴层次和交互，不宣称是原生材质。Electron 的 Windows Mica/Acrylic 仅在 Windows 11 22H2+ 支持，不能作为 Windows 10 的基础依赖。Tauri 的 Windows 前端仍为 Chromium WebView2，迁移不能自动获得 Apple 材质，且需重做数据库、密钥、IPC 与后台任务适配。本轮不换栈。

性能以相同隔离资料库比较两种外观：启动到首屏、进程 CPU / 工作集、静置及滚动帧间隔。报告测量环境和范围；进程 CPU 不等于整机功耗，无法据此保证风扇完全不转。保留分页、按需详情与现有安全边界。

## 行为修整

- 区分 AI 未完成与归属尚未决定。优先复用宽泛问题，避免笔记碎片化；手工归属、更正和删除仍保护。
- 思考与资料查证从当前对象一键启动，定制问题保留在次级入口。联网操作明确标注，检索词不直接使用私人正文；结果不自动改变认知。
- 分析进度在中间呈现，完成自动折叠并保留打开结果入口；失败与部分完成保持可见，禁止重复提交。

## 试用与隔离

实验安装包 `ChatNoteUki-0.5.2-glass.1-Setup-x64.exe` 安装为 **ChatNoteUki Glass**，使用独立 appId 与 `%APPDATA%/ChatNoteUki-Glass`。稳定版的安装、日常资料与凭据不被复制或更改；第一次试用为空白资料库，需要自行填写密钥。坚果云默认目录也独立为 `ChatNoteUki-Glass/`。不要把实验目录改为日常目录或接管日常云库；可以用少量新笔记验证交互。返回稳定版只需打开原来的 ChatNoteUki。

本轮没有换栈、没有新增真实 API 调用。原文、手动标题、归属与认知审批保护沿用原协议。自动查证额外使用一个可恢复的 Flash 步骤提炼检索词，界面无需重新输入问题。检索词会被 AI 泛化；本地额外拒绝邮箱、手机号、证件号与密钥样式，无法自动识别所有私人姓名，敏感主题可改用自定义查证核对词语。

笔记内「AI 思考」分析该条最新正文，结果在原卡片中展开，不制造用户追问或更改原文。「生成线程回顾」仍会纳入线程内的记录与讨论。完成的进度与回顾收为结果行；失败、部分完成保留重试入口。新归属建议直接附在相关笔记下，接受／拒绝规则与敏感度设置不变，整理建议页仍用于集中审批。

## 本机初步性能结果

10,000 条合成笔记，1440×900 窗口；使用开发可执行文件、同一隔离数据库与暖缓存，素雅／玻璃交错各两次。首屏均仅 30 条。

| 指标                | 素雅         | 玻璃         |
| ------------------- | ------------ | ------------ |
| 启动至首屏          | 653–660 ms   | 606–616 ms   |
| 空闲进程 CPU 平均值 | 0.053–0.180% | 0.029–0.032% |
| 应用进程工作集总和  | 454 MiB      | 421–442 MiB  |
| 滚动帧间隔 P95      | 17.2–17.6 ms | 16.8 ms      |
| 超过 50ms 的滚动帧  | 0            | 0            |
| 模糊表面数          | 0            | 2            |

记录视口宽约 1163px，输入区高约 117px。两组差异含系统调度与缓存噪声，且初测期间运行了桌面回归，不能据此声称玻璃更快。这不是冷启动、整机耗电、GPU 功耗或风扇测试；Electron 的基础内存成本仍然存在。可使用 `node scripts/benchmark-workspace.mjs` 重复隔离测量，原始报告位于 `.local/glass-benchmark-*/results.json`。

## 验证范围

本机类型检查、146 项单元测试、13 项桌面流程及 9 项发布器测试通过。桌面用模拟 AI / WebDAV，覆盖人工归属审批、一键思考及公开检索词规划、任务重试复用、结果原位展开、窄窗口、外观切换和自动同步；没有使用个人笔记或真实密钥。

NSIS 安装包已构建；其打包程序通过离线记录、重启恢复、中文 PDF / DOCX / 文本提取与附件恢复验收，确认沙箱和上下文隔离启用。此验收直接运行打包程序，未安装替换日常版。分支 CI 只构建并保存安装包，不发布为 main 的最新 release。
