# Liquid Glass 工作区实验

分支：`codex/liquid-glass-workspace`。基线：0.5.1 / `caa6e8c`。稳定 main 与日常资料保持独立。

## 第二次设计：透镜材质与整齐工具栏

第一版的轻微模糊缺少透镜感，本次以真实背景折射为主要视觉特征。色板：纸白 `#fbfcfe`、石墨 `#283449`、雾蓝 `#e8eef7`、湖蓝 `#3479b9`、折射冷光 `#bedaf9`、暖光 `#ead7c3`。字体仍为微软雅黑 / Segoe UI，正文 14px，标题 19px，工具 12px；内容左对齐，工具按 32px 高度与同一中线排列。

```
标题                                      [同步 | 概览]
搜索                                    [筛选与查询]
[线程回顾] [认知变化] [查证] [自定义] [Flash ▾] [问题操作 ▾]
任务进度 / 配置提示 / 错误（独立下一行，不推歪按钮）
──────────────── 笔记正文与对话 ────────────────
                   [悬浮透镜输入区]
```

材质采用圆角矩形法线生成的位移图，而非整面随机扭曲；边缘聚光、轻微 RGB 色散、双层悬浮阴影与方向性高光。滤镜作用于背景，控件文字、正文和输入文字不变形。只在工具胶囊与输入区应用折射，不给每条笔记加滤镜。位移图仅在尺寸改变时生成，不截图正文、不逐帧渲染；素雅、减少透明和高对比度模式停用折射。

参考 [React Bits GlassSurface](https://github.com/DavidHDev/react-bits/blob/main/src/ts-default/Components/GlassSurface/GlassSurface.tsx) 的 SVG 背景滤镜路线与 [rdev/liquid-glass-react](https://github.com/rdev/liquid-glass-react) 的背景 / 清晰内容分层；采用本项目自己的几何位移场与控件布局，不引入整套组件、鼠标跟随或 WebGL 运行循环。

## 设计与布局

方向是可阅读的桌面工作区：白色内容平面、石墨色正文、低饱和蓝色强调。微软雅黑 / Segoe UI，正文默认 14px，工具 12px。玻璃只用于导航和操作平面，不用于笔记正文，不叠加玻璃。

```
┌ 导航 200px ┬ 标题 / 搜索 / 紧凑操作 ─────────┬ 资料 280px（按需）┐
│ 新想法     │ 问题工具：思考 / 查证 / 更多    │ 概览、已确认认知 │
│ 记录与问题 │ 笔记原文 → 回应 → 卡片内讨论   │ 引用与历史结果   │
│            │ 进行中的工作展开，完成收为结果行│                  │
│ 次级入口   │ 底部悬浮输入区：附件 / 保存    │                  │
└────────────┴──────────────────────────────┴──────────────────┘
```

日常页面收起右栏；打开资料不改变阅读位置。宽窗口可三栏，窄窗口资料覆盖。标题、搜索、分页合并为紧凑行，日期定位按需展开。任务及编辑在中间，右侧负责查阅。悬浮位置限定为输入区、上下文工具与选择工具；卡片操作不漂浮到正文上。点击目标至少 28px，触屏适当加大；保留文字、键盘焦点与减少动效。

本机提供「玻璃 / 素雅」切换以及「减少透明效果」。不开启持续动画，不使用自定义 WebGL / WebGPU 着色器、鼠标跟随光效或整页模糊。玻璃限于小范围 SVG / CSS 背景滤镜，关闭透明后不执行滤镜。

## 技术选择

继续 Electron / React。Apple 原生 Liquid Glass 属于 Apple 平台；Windows 的 CSS 实验借鉴层次和交互，不宣称是原生材质。Electron 的 Windows Mica/Acrylic 仅在 Windows 11 22H2+ 支持，不能作为 Windows 10 的基础依赖。Tauri 的 Windows 前端仍为 Chromium WebView2，迁移不能自动获得 Apple 材质，且需重做数据库、密钥、IPC 与后台任务适配。本轮不换栈。

性能以相同隔离资料库比较两种外观：启动到首屏、进程 CPU / 工作集、静置及滚动帧间隔。报告测量环境和范围；进程 CPU 不等于整机功耗，无法据此保证风扇完全不转。保留分页、按需详情与现有安全边界。

## 行为修整

- 区分 AI 未完成与归属尚未决定。优先复用宽泛问题，避免笔记碎片化；手工归属、更正和删除仍保护。
- 思考与资料查证从当前对象一键启动，定制问题保留在次级入口。联网操作明确标注，检索词不直接使用私人正文；结果不自动改变认知。
- 分析进度在中间呈现，完成自动折叠并保留打开结果入口；失败与部分完成保持可见，禁止重复提交。

## 试用与隔离

实验安装包 `ChatNoteUki-0.5.2-glass.2-Setup-x64.exe` 安装为 **ChatNoteUki Glass**，使用独立 appId 与 `%APPDATA%/ChatNoteUki-Glass`。稳定版的安装、日常资料与凭据不被复制或更改；第一次试用为空白资料库，需要自行填写密钥。坚果云默认目录也独立为 `ChatNoteUki-Glass/`。不要把实验目录改为日常目录或接管日常云库；可以用少量新笔记验证交互。返回稳定版只需打开原来的 ChatNoteUki。已使用 glass.1 的用户安装此包后继续使用同一实验资料库。

本轮没有换栈、没有新增真实 API 调用。原文、手动标题、归属与认知审批保护沿用原协议。自动查证额外使用一个可恢复的 Flash 步骤提炼检索词，界面无需重新输入问题。检索词会被 AI 泛化；本地额外拒绝邮箱、手机号、证件号与密钥样式，无法自动识别所有私人姓名，敏感主题可改用自定义查证核对词语。

笔记内「AI 思考」分析该条最新正文，结果在原卡片中展开，不制造用户追问或更改原文。「生成线程回顾」仍会纳入线程内的记录与讨论。完成的进度与回顾收为结果行；失败、部分完成保留重试入口。新归属建议直接附在相关笔记下，接受／拒绝规则与敏感度设置不变，整理建议页仍用于集中审批。

## 首版基线性能（glass.1）

10,000 条合成笔记，1440×900 窗口；使用开发可执行文件、同一隔离数据库与暖缓存，素雅／玻璃交错各两次。首屏均仅 30 条。

| 指标                | 素雅         | 玻璃         |
| ------------------- | ------------ | ------------ |
| 启动至首屏          | 653–660 ms   | 606–616 ms   |
| 空闲进程 CPU 平均值 | 0.053–0.180% | 0.029–0.032% |
| 应用进程工作集总和  | 454 MiB      | 421–442 MiB  |
| 滚动帧间隔 P95      | 17.2–17.6 ms | 16.8 ms      |
| 超过 50ms 的滚动帧  | 0            | 0            |
| 模糊表面数          | 0            | 2            |

记录视口宽约 1163px，输入区高约 117px。两组差异含系统调度与缓存噪声，且初测期间运行了桌面回归，不能据此声称玻璃更快。这不是冷启动、整机耗电、GPU 功耗或风扇测试；Electron 的基础内存成本仍然存在。可使用 `node scripts/benchmark-workspace.mjs` 重复隔离测量，原始报告位于 `.local/glass-benchmark-*/results.json`。

## 第二版性能（glass.2）

第二版 `glass.2` 独立测量：Windows build 26300、i7-12700H、约 16 GiB RAM、Node 24.19；复用 10,000 条合成笔记到新隔离副本。没有同时运行测试或打包；仍为交错四次暖缓存开发程序启动，首屏 30 条。玻璃计时等待位移图就绪。

| 指标                | 素雅         | 透镜玻璃     |
| ------------------- | ------------ | ------------ |
| 首屏及材质就绪      | 595–726 ms   | 905–1,078 ms |
| 空闲进程 CPU 平均值 | 0.034–0.255% | 0.024–0.026% |
| 应用进程工作集总和  | 441–476 MiB  | 480–492 MiB  |
| 滚动帧间隔 P95      | 16.9–17.1 ms | 16.9–17.0 ms |
| 超过 50ms 的滚动帧  | 1            | 0            |

透镜有明确的首屏成本，样本内约多 0.3–0.4 秒；不是零开销。工作集含各进程共享页，不能当作独占内存。少量样本不足以比较谁更快，也不代表冷启动、整机功耗、GPU 耗电或风扇。原始报告位于 `.local/glass-benchmark-1791694037671/results.json`。重复测量可以向 `node scripts/benchmark-workspace.mjs` 传入已有 `.local/glass-benchmark-*` 路径，脚本验证其合成报告、复制到新目录后再测，不修改源资料。

## 验证范围

本机类型检查、14 项桌面流程通过，保留 146 项单元测试及 9 项发布器回归。桌面用模拟 AI / WebDAV，覆盖人工归属审批、一键思考及公开检索词规划、任务重试复用、结果原位展开、窄窗口、外观切换和自动同步；没有使用个人笔记或真实密钥。

新增渲染验收使用黑白斜条纹作为真实背景，比较实际折射与关闭位移的画面：边缘出现位移与 RGB 分色，中央像素保持一致。另验证所有顶部操作高度为 32px、同一行居中，切换 Flash / Pro 或打开选项不推动其他按钮；高对比度模式停用透镜，窗口缩放后位移图随尺寸更新。

NSIS 安装包已构建；其打包程序通过离线记录、重启恢复、中文 PDF / DOCX / 文本提取与附件恢复验收，确认沙箱和上下文隔离启用。此验收直接运行打包程序，未安装替换日常版。分支 CI 只构建并保存安装包，不发布为 main 的最新 release。
