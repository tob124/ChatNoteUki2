# ChatNoteUki 0.5.0：查找、摘录和指定范围观察

范围限定 F01、F03、F04，在 main 开发。保持记录优先、三栏、底部输入和原文保护，保留资料及本机凭据。

## 界面收敛

沿用颜色：底色 #f5f6f8，阅读区 #ffffff，正文 #30343b，辅助 #737b88，强调 #3777d2，分隔 #e5e8ee。微软雅黑阅读正文，不引入新装饰字体。原文左对齐，段落保持原换行，长内容按需展开。

布局仍为问题树／时间线与输入／资料。搜索行只常驻关键词与“筛选与查询”入口；范围、状态、更正历史、保存查询和已保存查询在同一展开层。多选条只在选择后出现，以“分析所选”为主要动作，移动和导出属于次要操作。资料阅读中选择文字后出现“摘录并记录想法”；核对摘录和写自己的想法在现有资料层完成，不增加全局标签页。

审查：不新增一级导航，不为三个功能各建一个永久面板；保存查询恢复筛选且保留工作区草稿，引用查阅不切走当前阅读位置。批量分析的数量和确认范围明确，窄窗口展开层可滚动，Escape 关闭后焦点回入口。

## 数据与闭环

保存查询采用事件保存名称、查询范围及筛选，不复制笔记；恢复时失效线程明确提示，不静默搜索其他范围。阅读位置仅本机保存。允许重命名及删除查询。

摘录保留文件哈希、提取段 ID、页码、段内 UTF-16 偏移和逐字片段。主进程核对来源后事务保存用户笔记和引用；来源片段属于资料，用户自己的理解属于正文。引用定位可核对源段，导出分开标记。删除资料后不泄露已删除源文，笔记仍保留；原件相同而提取改变时显示旧摘录并提示重新核对。

选定分析限制当前页最多 30 条用户笔记。确认具体问题和输入版本后建立持久任务；只分析选定笔记的最新正文；线程回顾仍按原设计纳入关联对话，不混入其他搜索命中。按 token 容量装入，超出时明确要求缩小范围或提高容量，不声称未读取内容已分析。结果保存为全局回顾，不更改归属或已确认认知；版本、删除及归属改变使结果过期。重复点击定位同一待完成任务，预算与取消沿用现有队列。

云端格式升级 6，读取 1–5，旧版不能维护新格式。新增字段兼容旧库，升级备份及事件重放保持原文、人工字段和凭据。草稿仍仅本机。

## 验收

新增单元测试覆盖保存查询重放与失效范围、引用偏移／文件身份校验、重复保存和来源删除、更正或删除时分析结果过期、明确范围和预算。桌面路径覆盖“保存查询→切换→恢复”“选资料文字→记录想法→引用→导出”“选多条→确认范围→分析结果→原文核对”，并检查窄窗口及键盘。

全量回归、类型、凭据扫描、Windows CI 通过后发布安装包，并以隔离合成资料实测安装升级、离线记录及重启恢复。日常验收使用模拟接口，本轮不新增付费调用。
