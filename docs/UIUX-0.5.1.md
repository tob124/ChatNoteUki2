# 0.5.1：日常界面修整

本轮遵循“使用、反馈、打磨”，保留既有功能与云端格式 6，不新增资料迁移。

## 设计约束

- 背景 `#FFFFFF`，辅助表面 `#F5F6F8`，正文 `#313338`，次要文字 `#626B77`，分隔线 `#E6E7EA`，强调 `#336BAF`。
- 微软雅黑：正文沿用用户阅读字号（默认 14px），辅助文字至少 12px；标题 20px。所有文字左对齐。
- 三栏保留，中央阅读优先。低频操作在当前位置展开；表单错误、保存反馈与任务状态靠近操作。不新增常驻导航入口。

```text
左栏                    中间                       右栏
新想法 / 记录            当前页面 / 同步 / 概览        问题概览 / 问题操作菜单
回顾 / 资料              搜索 + 筛选                  已确认认知
问题树                   分页 + 日期                 AI 分析（回顾 / 认知变化）
                        时间线                      参考资料 / 历史
设置 / 回收站            底部草稿 + 添加资料 + 保存
```

已对照用户要求复查：保持安静的记录工具，时间线与底部输入不变；不把资料分析做成另一个首页，不增加装饰卡片或新的配色。已有功能通过分组与按需展开收敛。

## 修整范围

1. 页面标题、搜索范围与空页面文案反映当前位置；导航显示当前页语义。
2. 笔记操作避开标题，搜索结果减少重复展示；短原文与 AI 摘要维持不同标签与颜色。
3. 记录框集中添加资料、系统听写、保存与草稿状态；辅助工具按需展开。
4. 问题管理收进菜单，右栏清楚分组；高级模型与设置参数按需展开。
5. 菜单统一单开、点击外部关闭、Escape 关闭并恢复焦点；弹窗标注名称。
6. 辅助文字、窄窗口、长标题、低高度窗口及减少动效检查。

## 验证

- 本地类型检查、141 项单元测试与 12 个桌面流程通过。新增流程覆盖菜单单开、外部点击、键盘关闭、弹窗焦点、设置未保存保护、空页面提示与 900×640 布局。
- 9 项发布脚本测试通过；源码凭据扫描在提交前执行。
- 截图用隔离的合成资料检查三栏、窄窗口和设置；真实个人资料未进入测试。
- 顺带修复切换页面时注销刷新订阅、丢弃尚未执行的刷新通知的问题；保留分页与原阅读位置。
- 未调用真实 AI，不改数据库、AI 请求或同步协议。安装与 Windows CI 结果在交付时记录。
